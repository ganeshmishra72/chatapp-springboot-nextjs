
# ⚙️ Backend - ChatApp

Spring Boot backend for the real-time ChatApp project.

---

# 🚀 Tech Stack

- Spring Boot
- Spring WebSocket
- STOMP
- MongoDB
- Maven
- Lombok
- Docker

---

# ✨ Features

- Real-time WebSocket communication
- Chat room creation
- Store chat history
- MongoDB integration
- REST APIs
- STOMP messaging support
