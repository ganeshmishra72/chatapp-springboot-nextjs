# 🎨 Frontend - ChatApp

Modern frontend for ChatApp built with Next.js and TypeScript.

# 🚀 Tech Stack

- Next.js 15
- React.js
- TypeScript
- Tailwind CSS
- Zustand
- React Query
- Framer Motion
- STOMP.js
- SockJS
- Axios
- React Icons

# ✨ Features

- Real-time chat UI
- Responsive design
- Create and join rooms
- Live message updates
- Beautiful animations
- Toast notifications
